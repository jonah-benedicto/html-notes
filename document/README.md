# Document

```html
<!DOCTYPE html>
<html>
<body>

<h1>My First Heading</h1>
<p>My first paragraph.</p>

</body>
</html>
```

## `<!DOCTYPE>` Declaration
Declares the document type.
```html
<!DOCTYPE html>
```

## Headings
Headings are defined with `<h1>` to `<h6>`.
```html
<!DOCTYPE html>
<html>
<body>

<h1>This is heading 1</h1>
<h2>This is heading 2</h2>
<h3>This is heading 3</h3>
<h4>This is heading 4</h4>
<h5>This is heading 5</h5>
<h6>This is heading 6</h6>

</body>
</html>
```

## Paragraphs
Paragraphs are defined with `<p>`.
```html
<!DOCTYPE html>
<html>
<body>

<p>This is a paragraph.</p>
<p>This is another paragraph.</p>

</body>
</html>
```

## Links
Links are defined with `<a>`.
```html
<!DOCTYPE html>
<html>
<body>

<a href="https://www.github.com">This is a link</a>

</body>
</html>
```

## Images
Images are defined with `<img>`.
```html
<!DOCTYPE html>
<html>
<body>

<img src="Copilot_Icon_Black_Clearspace.png" alt="Copilot Icon Black Clearspace">

</body>
</html>
```
